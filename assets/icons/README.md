# 🎨 โครงสร้างและการจัดการไอคอนแอป (App Icons Management)

คู่มือและโครงสร้างไฟล์ไอคอนมาตรฐานของโปรเจกต์ **DeepSeek Harness**

---

## 📁 ตารางไฟล์ไอคอนและขนาดการใช้งาน

| ไฟล์ | ขนาด | วัตถุประสงค์ / การใช้งาน |
|---|---|---|
| `icon-16.png` | 16×16 px | Favicon ขนาดเล็กสำหรับเบราว์เซอร์ |
| `icon-32.png` | 32×32 px | Favicon มาตรฐานบนเว็บเบราว์เซอร์ / แท็บ |
| `icon-48.png` | 48×48 px | Taskbar Windows / System Tray / เมนูย่อย |
| `icon-128.png` | 128×128 px | หน้าต่าง About / ข้อมูลโปรแกรม |
| `icon-256.png` | 256×256 px | Windows Desktop App / กล่อง Shortcut ใหญ่ |
| `icon-512.png` | 512×512 px | ภาพต้นฉบับความละเอียดสูง (HD Source) |
| `apple-touch-icon.png` | 180×180 px | หน้าจอโฮม iOS / PWA (Web App) |
| `icon.ico` | Multi-size (16, 24, 32, 48, 64, 128, 256) | ไฟล์ไอคอนมาตรฐาน Windows Executable & Shortcuts |

## 🔄 วิธีเปลี่ยนและสร้างไอคอนใหม่ (Self-Service Icon Generation)

หากต้องการเปลี่ยนไอคอนของแอปพลิเคชันเป็นรูปภาพใหม่ ให้ทำตามขั้นตอนดังนี้:

1. **เตรียมรูปภาพต้นฉบับ:**
   - เตรียมไฟล์รูปภาพ PNG สี่เหลี่ยมจัตุรัสที่มีความละเอียดอย่างน้อย **512×512 px** (หรือ 1024×1024 px)
2. **วางไฟล์ทับรูปเดิม:**
   - ตั้งชื่อไฟล์ว่า `icon-512.png` แล้วนำมาวางทับไฟล์เดิมในโฟลเดอร์ `assets/icons/`
3. **สั่งรันสร้างไอคอนอัตโนมัติ:**
   - ดับเบิลคลิกที่ไฟล์ `generate-icons.bat`
   - ระบบจะแปลงภาพต้นฉบับเป็นทุกขนาด (16px - 512px), สร้างไฟล์ `icon.ico` แบบ Multi-size พร้อมอัปเดตไฟล์ `desktop-host/app.ico` และ `deepseek-harness.ico` โดยอัตโนมัติทันที
